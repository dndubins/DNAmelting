### DNA Melting Curve Programs
Clarifying the terminology:<p>
Self-complementary, n=1 (Unfolded <-> Folded)<p>
Self-complementary, n=2 (SS1 + SS1 <--> Duplex)<p>
Non-self-complementary, n=2 (SS1 + SS2 <-> Duplex)<p>
Self-complementary, n=3 (3 x SS1 <--> Triplex)<p>
Self-complementary, n=4 (4 x SS1 <--> Quadruplex)<p>
