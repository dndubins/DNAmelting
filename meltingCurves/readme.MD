### DNA Melting Curve Programs
These programs are for DNA melting curves:
Self-complementary, n=1 (Unfolded <-> Folded)
Self-complementary, n=2 (SS1 + SS1 <--> Duplex)
Non-self-complementary, n=2 (SS1 + SS2 <-> Duplex)
Self-complementary, n=3 (3 x SS1 <--> Triplex)
Self-complementary, n=4 (4 x SS1 <--> Quadruplex)
